# Data-Analytics-Internship

This repository contains my weekly assignments and projects completed during the internship. The projects demonstrate my practical experience in **Microsoft Excel, Python, Pandas, data cleaning, data wrangling, statistical analysis, data visualization, dashboards, machine learning, and business analytics**.

---

## 📌 Internship Overview

The internship consists of multiple weekly tasks designed to develop practical data analytics skills.

The projects progress from basic Excel-based analysis to Python and Pandas data processing, followed by a comprehensive Sales Analytics Capstone project.

### Skills Covered

- Data Cleaning
- Data Preprocessing
- Missing Value Handling
- Duplicate Detection and Removal
- Statistical Analysis
- Data Wrangling
- Exploratory Data Analysis (EDA)
- Data Visualization
- Pivot Tables
- Conditional Formatting
- Excel Dashboards
- Python Programming
- Pandas
- Machine Learning
- Regression Analysis
- Business Insights
- Power BI Dashboard Preparation
- Git and GitHub
